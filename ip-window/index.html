Privacy, in plain English

This is a personal educational tool maintained by kkyian. Its only purpose is to display your own connection details to you. This page has no analytics, advertising, cookies, browser storage, tracking pixels, or visitor database. The page’s code does not send lookup results to the site owner.

Loading the site still connects you to GitHub Pages, whose infrastructure receives your IP and may keep connection logs. If you agree to a lookup, IPWhois also receives your IP and connection metadata; processing may occur outside your country. Their own policies and retention practices apply. Clearing the screen cannot erase providers’ logs or undo a request already sent.

You can decline by leaving the lookup unused, or stop further lookups with Clear results. For questions about this page, use the owner’s GitHub profile; never post your IP in a public issue. For provider-held data requests, contact the relevant provider.
